# Code of Conduct

Lin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, insults, and personal or political attacks
are not acceptable in issues, pull requests, discussions or anywhere else the project lives.

Problems can be reported privately to the maintainers through GitHub
(**Security → Report a vulnerability** works for this too, if nothing else fits). Reports are
handled confidentially, and maintainers may remove content or block anyone who breaks these
rules.
